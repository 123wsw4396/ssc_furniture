# SSC Furniture

Furniture mod for the Shape Shifter's Curse server, built for Fabric.

## Features

- Bathtub bed & water bed (two-block beds with sleep support)
- Bat climbing scaffold (ceiling perch)
- Digestion web box
- Four-legged cushion (seats)
- Gust cloth with dyeing system (foot binding)
- Shaping grappling hook (silk launcher with physics)
- Various compatibility tools for Shape Shifter's Curse forms

## Requirements

- Minecraft `1.20.1`
- Fabric Loader `>= 0.19.2`
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Shape Shifter's Curse](https://modrinth.com/mod/shape-shifters-curse) `>= 1.10.0`
- [GeckoLib](https://modrinth.com/mod/geckolib) `>= 4.0.0`
- [Trinkets](https://modrinth.com/mod/trinkets) `>= 3.7.2` (recommended)

## Build

```sh
./gradlew build
```

The jar is output to `build/libs/`.
